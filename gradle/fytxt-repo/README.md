# FYTxt and FVV

Copies of the FYTxt 2.2607.6 Gradle plugin and runtime and of FVV 2.2, from
[ShiroSU FYL](https://github.com/OOM-WG/ShiroSU-FYL). The locale module generates `YumeTxt` with them.

KimiNoBox keeps these files here because the Maven repository they were published to is no
longer online, so a build on a clean machine, such as in GitHub Actions, could not resolve them.
They are unchanged. Their license is the File to Downloader License in `../../LICENSE-F2DL`.
